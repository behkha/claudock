  • Installers

    Mac Apple silicon Mac Intel Windows Linux AppImage Linux .deb

    macOS
    Open it once, click Done, then Open Anyway in System Settings › Privacy & Security. If macOS says the app is damaged, run xattr -dr com.apple.quarantine /Applications/Claudock.app.
    Windows
    Click More info, then Run anyway.

Safe by design

  • Snapshot before every writeSaved outside ~/.claude. Diff and restore from Backups.
  • Atomic writesTemp file, then rename. JSON is validated first.
  • Trash, not deleteDeletes go to the OS Trash.
  • Never reads credentials.credentials.json and sessions/*.key show as locked rows.
