Safe by design

  • Snapshot before every write

    Saved outside ~/.claude. Diff and restore from Backups.

  • Restore a file from before you broke it

    Compare the snapshot with the current file, then restore.

  • Atomic writes

    Temp file, then rename. JSON is validated first.

  • Trash, not delete

    Deletes go to the OS Trash.

  • Never reads credentials

    .credentials.json and sessions/*.key show as locked rows.

    sessions/*.key

    > irm https://behkha.github.io/claudock/install.ps1 | iex

    • Mac Apple silicon

    • Linux AppImage

    macOS
    Open it once, click Done, then Open Anyway in System Settings › Privacy & Security.
    If macOS says the app is damaged, run
    $ xattr -dr com.apple.quarantine /Applications/Claudock.app

    Click More info, then Run anyway.
