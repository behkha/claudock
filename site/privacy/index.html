Claudock GitHub

Privacy

Claudock has no telemetry, no account and no server of its own. Your config stays on your computer.

What the app reads

The Claude Code config folder (~/.claude, or the folder in CLAUDE_CONFIG_DIR) and the MCP servers in ~/.claude.json. It never reads .credentials.json or sessions/*.key. Snapshots of the files it changes, and its cache of the settings docs, are kept in Claudock's own app data folder on your computer.

Network requests the app makes

HostWhat forWhen
code.claude.comAnthropic's public settings reference and environment variables pages, for the JSON editor's suggestionsAt launch
json.schemastore.org and raw.githubusercontent.comThe Claude Code settings JSON schema, asked of both at once; the first answer is usedAt launch
api.github.comThe latest Claudock release, to show a notice when a newer one is outAt launch, at most every six hours, in installed copies only

These are ordinary downloads. They send nothing about your config, though like any web request they show the host your IP address. The request to api.github.com names the Claudock version in its user agent. Start the app with CLAUDOCK_OFFLINE=1 to turn all three off; the editor then uses the copy of the docs bundled with the app.

Links you click open in your browser. On the Share stats card, Post on X opens x.com's compose page in your browser with the post text filled in; nothing is posted until you post it there. Copy image and Save PNG keep the image on your computer.

Installing

npx claudock downloads the package from the npm registry, and Electron's install step downloads Electron from GitHub. The installers download from GitHub Releases. Those services' own privacy terms apply.

This website

The site is hosted on GitHub Pages, which logs visitors' IP addresses (see GitHub's privacy statement). It sets no cookies and has no analytics. The home page loads its animation library from cdnjs.cloudflare.com and asks api.github.com for the latest release's download links, which it keeps in your browser's session storage for ten minutes.
