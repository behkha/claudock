ccusage with a GUI

ccusage is the standard way to see what Claude Code costs. It reads your local session logs and prints daily, monthly, session and 5-hour reports in the terminal. It's free, fast, updated almost daily, and reads the logs of 17 other agent CLIs too.

It's a CLI by design. Its live dashboard was removed in v18, and it has no app of its own; its docs list menu bar apps and dashboards made by other people. If you want the same numbers in a window, here's what exists.

CC Switch

The fullest GUI for ccusage's kind of numbers. It reads your session logs for tokens, cache hit rate and spend, draws a heat map and keeps per-request logs. It shows how much subscription quota is left, with a reset countdown, on its cards and in the tray. Usage is one part of a bigger app that switches API providers and manages MCP servers, skills and prompts across twelve CLIs. Signed builds, auto-update.

Good fit if you want ccusage's numbers plus your quota in the tray, and don't mind a larger app. Claudock vs CC Switch

Claudock

A desktop app for Claude Code's ~/.claude folder, with your limits in the menu bar. After one Connect step, it shows the 5-hour and weekly percentages exactly as Claude Code reports them, with their reset times, and never estimates one. Until a terminal session reports them, or on Windows, it shows the tokens used in each window, counted from your transcripts. Its Share card puts one cost estimate on each week: what it would have cost at Anthropic's API prices, beside the plan you pick.

It also shows which sessions are running or waiting for you, alerts you when one starts waiting, and has a screen for every part of your setup: settings, hooks, permissions, skills, agents, commands, plugins and MCP servers.

Good fit if you want your real limits at a glance and your setup in one window. Keep ccusage alongside it for cost reports.

Claude Code Usage Monitor

Not a GUI, but the closest thing to ccusage's old live dashboard. It's a Python terminal app with progress bars for the 5-hour window, burn rate, reset countdown and forecasts. With its status line step added, it shows the official 5-hour and 7-day percentages and labels every number by where it came from. Its README points to separate menu bar companions.

Good fit if you live in the terminal and want official limits with forecasts.

opcode

A desktop app for running Claude Code sessions and agents, with a usage dashboard: cost and tokens by model, project and date, charts and export. Its README lists usage alerts as "coming soon". Its latest release is v0.2.0 from 31 August 2025, with no Windows installer.

Good fit if you also want to run sessions from a window. Claudock vs opcode

Keep ccusage

For exact numbers, ccusage is still the reference: per-model cost with cache tokens, offline pricing, filters, JSON output and a status line. Every app above shows estimates from the same local logs. ccusage's own docs say costs may not match actual billing, and the same goes for the apps above.

FAQ

Does ccusage have a GUI?

Not from the project. It's a CLI with a status line mode. Its docs list menu bar apps and dashboards made by other people.

Which GUI shows my Claude Code 5-hour limit?

CC Switch shows subscription quota with a reset countdown in its tray. Claudock shows the 5-hour and weekly percentages Claude Code reports, in the menu bar. Claude Code Usage Monitor shows them in the terminal.

Are these numbers exact?

Cost is estimated from local logs in every tool here. Limit percentages are exact only when they come from Claude Code itself, through its status line.
